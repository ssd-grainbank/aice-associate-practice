# AICE Associate 연습문제 100선

실제 시험과 같은 **주피터 방식**입니다. 보기(객관식)는 없습니다. 코드를 직접 칩니다.

> **클로드 코드(Claude Code) 쓰는 분**: 이 폴더를 열고 "README 보고 세팅해줘"라고 하면
> 아래 설치부터 `aice` 명령어 등록까지 알아서 해줍니다. 그게 제일 편합니다.

## 처음 받았다면 — 설치 (1번만)

맥 기준입니다. 터미널을 열고:

```bash
# 1. 파이썬 확인 (버전이 나오면 OK)
python3 --version

# 2. 필요한 라이브러리 설치
pip3 install pandas numpy scikit-learn matplotlib
```

## 시작하기

**방법 A — 그냥 바로 실행** (설정 필요 없음)

```bash
cd "이 폴더 경로"      # 예: cd ~/Desktop/AICE-Associate-대화형-학습
python3 exam.py        # 20세트 목록 보기
python3 exam.py 1      # 1세트(1~5번 문제) 풀기
python3 exam.py 1 -a   # 정답을 보며 따라치기 (막힐 때)
```

**방법 B — 더블클릭** : 폴더 안의 **`시험시작.command`** 를 더블클릭해도 됩니다.
(처음 한 번 "확인되지 않은 개발자" 경고가 뜨면: 우클릭 → 열기)

**방법 C — 어디서든 `aice` 한 단어로 실행** (선택)

`~/.zshrc` 파일 맨 아래에 다음을 추가하세요. **경로는 본인이 폴더를 둔 위치로 바꿔야 합니다.**

```bash
aice() {
  ( cd "$HOME/Desktop/AICE-Associate-대화형-학습" && python3 exam.py "$@" )
}
```

저장 후 터미널을 새로 열면(또는 `source ~/.zshrc`) 어느 폴더에서든 됩니다:

```bash
aice          # 목록
aice 1        # 1세트 풀기
aice 1 -a     # 정답 보며 따라치기
```

## 푸는 법

1. 문제를 읽고 `[1]:` 칸에 코드를 칩니다
2. **엔터 두 번** → 실행되고 바로 채점됩니다
3. 모르면 빈 채로 **엔터 두 번** → 정답과 해설이 나옵니다
4. 틀려도 정답이 자동 실행되므로 뒤 문제를 계속 풀 수 있습니다

## 20세트 구성

공식 출제범위 배점(분석 30 / 전처리 30 / 모델링 40)에 맞췄습니다.

| 세트 | 문제 | 내용 |
|---:|---:|---|
| 1~5 | 1~25 | **데이터 분석** — read_csv, head, shape, info, describe, value_counts, groupby, 정렬, 상관계수 |
| 6~11 | 26~55 | **전처리** — 결측치(평균·중앙값·최빈값), 중복, IQR 이상치, 원핫·라벨 인코딩, 스케일링, train_test_split |
| 12~17 | 56~85 | **모델링** — 로지스틱회귀, 랜덤포레스트, 결정트리, KNN, 선형회귀, 평가지표, 교차검증, 신경망 |
| 18~20 | 86~100 | **실전 혼합** — 분석부터 모델링까지 한 흐름으로 |
